# V0.4 에셋 현황 (Stage 2~5)

`버거 재료.zip`(5종 버거, PNG 43개로 보고됨)은 **이 작업 환경과 저장소에 없다.** 따라서 저장소에 이미 있던
이미지와 코드로 그린 임시 SVG만 사용했다. 기존 원본 이미지는 수정·삭제하지 않았다. Stage 1 에셋 현황은
`docs/v0.3-assets.md` 그대로 유효하다.

## 이번에 사용한 기존 이미지 (V0.3에서 미사용이던 파일)

| 파일 | 실제 그림 | 사용처 | 상태 |

| `assets/lettuce.webp` | 양상추 | 베이컨치즈 재료 아이콘·층 | 기존 에셋 (위에서 본 시점을 눌러서 층으로 사용) |

## 최종 그래픽 요청 목록 (정확한 산출)

규격은 `docs/v0.3-assets.md`와 동일: 투명 WebP, 표시 크기 3배, 좌상단 조명, 프리미엄 3D 토이 스타일.

### Stage 2 (6개)
1. `fries.webp` — 빨간 SLUMDUNK 종이 케이스 감자튀김 (주문 말풍선·재고 아이콘)
2. `drink.webp` — SLUMDUNK 컵 + 빨대
3. `fryer_body.webp` — 프라이어 본체(기름 포함)
4. `fryer_basket.webp` — 바스켓 단독(내려가는 애니메이션용)
5. `fountain.webp` — 음료 기계
6. `combo_set.webp` — 버거+감자+음료 세트 트레이(스테이지 카드·SET 연출용, 선택)
