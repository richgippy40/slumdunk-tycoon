# V0.3 에셋 현황 (임시 / 최종)

Art Direction V1.0 기준. **임시** 항목은 코드로 그린 대체 그래픽이며 최종 디자인이 아니다.
최종 에셋이 오면 표의 "교체 위치"만 바꾸면 되고 게임 로직은 수정할 필요 없다.

| 에셋 | 현재 | 상태 | 교체 위치 |
| --- | --- | --- | --- |
| 손님 캐릭터 4종 × 표정 5개 (기본/기다림/초조/기쁨/화남) | SVG 도형 (S캡 소년, 빨간 리본 소녀, 민트 비니+안경, 곱슬머리) | **임시** | `js/art.js` `customerSVG()` |
| 레트로 다이너 배경 (벽, 창, 조명, 부스, 체커, 네온, 카운터) | CSS 그라디언트 + SVG | **임시** | `index.html` `.diner`, `css/game.css` Diner 섹션 |
| 그릴 | CSS | **임시** | `css/game.css` `.grill`, `.grate`, `.embers` |
| 조립 접시 | CSS | **임시** | `css/game.css` `.plate` |
| 버거 층: 아랫번 / 패티 / 윗번 | 기존 `bun_bottom`, `beef_ready`, `bun_top` 이미지를 눌러서 사용 | 기존 에셋 재사용 (측면 레이어 아님) | `js/art.js` `LAYERS` |
| 버거 층: 소스 / 피클 / 치즈 / 카라멜어니언 | SVG | **임시** | `js/art.js` `LAYERS` |
| 재료 아이콘: 아랫번 / 패티 / 치즈 / 윗번 | 기존 이미지 | 기존 에셋 | `js/art.js` `ICONS` |
| 재료 아이콘: 소스 / 피클 / 카라멜어니언 | SVG | **임시** | `js/art.js` `ICONS` |
| 그릴 위 패티 (생/굽는 중/완성/탐) | 기존 `beef_*` 4종 | 기존 에셋 (사실적 질감 — 토이 스타일 재제작 검토) | `js/main.js` render Grill |
| 주문 말풍선 버거, 동전, 하트, 화남 표시, 자물쇠, 아이콘류 | SVG | **임시** | `js/art.js` |
| 효과음 (탭, 굽기, PERFECT/GOOD/MISS, 동전, 손님 반응, 종료) | Web Audio 합성음 | **임시** | `js/audio.js` |
| 로고 | CSS 텍스트 | **임시** | `css/game.css` `.logo` |

사용하지 않는 기존 파일: `pickle.webp`(실제 그림은 버섯), `onion.webp`(실제 그림은 계란 프라이),
`lettuce.webp`, `tomato.webp`, `bacon.webp`. 삭제하지 않고 그대로 둔다.

## 최종 에셋 규격 (요청 시 기준)
- 투명 배경 WebP, 표시 크기의 3배 해상도, 왼쪽 위 따뜻한 조명, 정면 약 30° 위 시점
- 버거 층 7종은 **같은 가로폭**(900px)·같은 시점의 측면 이미지
- 손님: 허리 위, 정면, 600×600, 표정 5종
